REPIQR MSG91 WHATSAPP TEMPLATE CONFIGURATION

LANGUAGE
English en

GENERAL RULES
Use the exact template names below.
Use the Utility category unless another category is specified.
Use named variables exactly as written.
Do not replace named variables with numbered variables.
Do not put a variable at the beginning or end of a template.
For Add Sample, enter a value in every variable field.
Use demo values only. Do not use real customer data.

TEMPLATE 1
Name: qr_scan_alert
Category: Utility
Variables:
{{label}} = tag label
{{message}} = visitor message
{{link}} = dashboard URL
Body:
RepiQR alert: someone just scanned your registered tag "{{label}}" and reported the following: "{{message}}". Open your RepiQR dashboard here: {{link}} to view details and respond securely.
Sample values:
{{label}} = Demo Tag 1234
{{message}} = A visitor sent a test alert.
{{link}} = https://example.com/dashboard
