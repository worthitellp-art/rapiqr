BEFORE YOU START EACH TEMPLATE:
Set the "Variable Type" dropdown to "Name" FIRST, before typing anything into
Body. If it's left on "Number" (MSG91's default for a new template), typing
{{label}} into Body will fail with: "Variables parameters must be whole
numbers with two sets of curly brackets, i.e., {{1}} or {{2}}." That error
means the dropdown is wrong, not that the body text is wrong - do not rewrite
{{label}} as {{1}} to fix it, switch the dropdown back to Name instead. Every
template below (except otp_verification, which has no Body field at all) uses
Name.

NOTE ON META DELETION LOCK ERROR:
If MSG91 says: "New english content can't be added while the existing english
content is being deleted. try again in less than 1 minute or consider creating
a new message template":
Meta locks a template name for a few minutes after it is deleted. Simply append
"_v2" to the Template Name (e.g. "emergency_contact_alert_v2") to bypass the
lock instantly without waiting. The backend code already supports this name.
